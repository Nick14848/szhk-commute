## 本地演示工具

运行 `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort` 后打开 `http://127.0.0.1:5174/tools/capture.html`，可游玩手机尺寸预览、导出竖屏演示。工具不在生产 dist 中；自动保存只接受 loopback 同源 MP4 请求，拒绝超过80MB的输入和覆盖已有文件。

视频是「实际游戏引擎 + 自动输入 + 分区片段剪辑」的竖屏导出，非实体手机/系统录屏，非连续通关。片内保留说明，无配乐音轨。1080×1920，H.264 MP4；帧率以实际检查结果为准，不宣称目标30fps就是实测恒定30fps。

视频与抽帧本地保留在 video/ 等目录，不把大视频、原始私人参考照片推入 main。保留的 Swift 工具可完整解码、核对参数和抽帧，检查报告随本地交付。

最终交付候选 `video/szhk-commute-vertical-1793064608094.mp4` 已完整解码：56.530 秒、1080×1920、H.264/avc1、1168 帧、nominal/平均约20.66fps（可变帧率）、22,589,713 bytes、无音轨。不是恒定30fps，不把它当手机系统录屏或真机测试。已修录制工具边框导致右缘露底和结算淡入首帧被缓存透明的问题，最终抽帧另存 final-delivery-frames/。
